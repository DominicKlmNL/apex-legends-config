<div id="Video Settings">

## Video Settings

<p>For the best compatible optimization for the combination of these files, we have to make sure the (video) settings for Apex Legends in-game are also properly configured.</p>

</div>

<br>

<div id="Installation" align="left">

## Installation 🕐

| Expected duration: |
| :--- | 
| $\color{green}\textsf{approx. 10 min}$  |

<p> 1. Open Steam and go to your <b>Library</b> tab </p>
<p> 2. Right+click <b>Apex Legends</b> </p>
<p> 3. Launch <b>Apex Legends</b> </p>
<p> 4. Go to <b>Settings</b> </p>
<p> 5. Switch to the tab <b>Video</b> </p>
<p> 6. Configure the <b>Settings</b> as listed in Table A </p>
<p> 7. Click Apply once you completed all the settings in <b>Video</b> as listed in $\color{green}\textsf{Table A}$ </p>
<p> 8. Switch to the tab <b>Advanced Video</b> </p>
<p> 9. Configure the <b>Settings</b> as listed in Table B </p>
<p> 10. Click Apply once you completed all the settings in <b>Advanced Video</b> as listed in $\color{blue}\textsf{Table B}$ </p>
<p> 11. Restart Apex Legends, to ensure that all the settings are loaded entirely and verify if everything is working</p>
<p> 12. Start off in the firing range and see if the settings are feeling better. If you run into any issues, you can always send a note here.</p>

<br>

$\color{red}\textsf{NOTE}$ : If you want to start using the autoexec.cfg combined with these settings, make sure to follow the instructions from [README](https://github.com/DominicKlmNL/apex-legends-config/edit/main/README.md) on how to install the configuration. If you also want to set the [Videoconfig.txt](https://github.com/DominicKlmNL/apex-legends-config/edit/main/videoconfig.txt), follow the instructions on the page.

<div id="Overview">

## Overview of the settings categorized

<br>

#### Table A. Display Settings

| Setting | Function | Value |
| :--- | :--- | :--- |
| Display Mode | Display Mode sets the game to fun full-screen, borderless window or run in window | Full Screen |
| Aspect Ratio | In the Full Screen  Display Mode it is recommended that you choose the native Aspect Ratio for your display in order to avoid stretching | Native |
| Resolution | Resolution sets the detail of the game screen | Native |
| Brightness | Controls the game's overal brightness | 50% |
| Field of View (FOV) | How zoomed-out the view appears by default. Settinbg this above 90 may impact performance or cause visual issues | 110 |
| FOV Ability Scaling | Scale your FOV when using movement abilities that increase your speed | Disabled |
| Sprint View Shake | Strength of view movement when sprinting | Minimal |
| UI Layout Mode | Changes the layout of the game UI | Full |

<br>

#### Table B. Video Settings

| Setting | Function | Value |
| :--- | :--- | :--- |
| V-Sync | Vertical Sync controls the trade-off between screen "tearing" and the time it takes for your actions to appear on screen (Input lag) | Disabled |
| Nvidia Reflex | Nvidia Reflex is used to reduce system latency which increases PC responsiveness | Enabled + Boost |
| Adaptive Resolution FPS Target | Dynamically lowers rendering resolution to maintain the specified target framerate | 0 |
| Adaptive Supersampling | Adaptive Resolution FPS Target, this setting forces the game to render at a higher resolution than your monitor's native display. It then downsamples the image to fit your screen.  It is a massive resource hog that introduces heavy GPU load and can severely tank your frame rate. | Disabled |
| Anti-Aliasing | Smoothes out the jagged edges ("jaggies") on objects and geometry, None: Maximizes your frame rate and clarity. | None |
| Texture Streaming Budget | Determines how much of your graphics card's dedicated memory (VRAM) the game is allowed to allocate for loading high-resolution textures. | Medium (3GB) |
| Texture Filtering | Controls how sharp and detailed textures look when viewed at an angle or from a distance. | Bilinear |
| Ambient Occlusion Quality | Controls the realism of shadows in corners, crevices, and areas where two surfaces meet. It adds depth to the environment, but it is one of the most resource-heavy settings in the game. | Disabled |
| Sun Shadow Coverage | Controls how much of the map is covered by shadows cast by the sun. Specifically, it dictates whether distant objects, trees, and terrain cast shadows or if they only appear when you get close. | Low |
| Sun Shadow Detail | Determines the resolution and sharpness of the shadows cast by the sun. For the highest frame rates and best visual clarity, set this to Low. | Low |
| Spot Shadow Detail | Controls the resolution and presence of shadows cast by indoor and artificial light sources (like lamps, flares, and arena floodlights). this setting can be turned completely OFF, which is highly recommended for competitive play. | Disabled |
| Volumetric Lighting | Controls the "god rays" or visible beams of light that shine through air, fog, dust, and smoke. | For competitive gameplay, this setting should always be DISABLED (Off). |
| Dynamic Spot Shadows | Controls whether moving light sources (like character abilities, care packages dropping, or moving map elements) cast dynamic shadows, and whether indoor shadows update in real-time as objects move. | For competitive play, this setting should always be DISABLED (Off) |
| Model Detail | Controls the geometric complexity and visual quality of character models, weapons, abilities, and environmental objects. | Low |
| Map Detail | Controls the complexity of the world's terrain, including things like grass, rocks, debris, and distant environmental structures. | Low |
| Effects Detail | Controls the visual quality, particle density, and duration of explosions, muzzle flash, ability animations (like Gibraltar’s dome or Bangalore’s smoke), and thermite fire. | this setting should strictly be set to Low. |
| Impact Marks | Determines whether bullet holes, scorch marks from explosions, and thermal burns remain visible on walls, floors, and objects. | Disabled |
| Ragdolls | Controls the movement of dead player models | Low |
